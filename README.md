# Marcel Wack

Mathematician and developer. Ph.D. student in the [Discrete Mathematics/Geometry group](https://www.math.tu-berlin.de/fachgebiete_ag_diskalg/fg_diskrete_mathematik_geometrie/v_menue/diskrete_mathematik_geometrie/) at TU Berlin.

I work on computational methods in combinatorics and algebra, mostly at the intersection of quantum information theory and matroid theory.

## Software

| Project | Description |
|---|---|
| [OSCAR](https://github.com/oscar-system/Oscar.jl) | Computer algebra system in Julia. I develop its non-commutative algebra parts. |
| [libisotopy](https://doi.org/10.48550/arXiv.2604.09221) | C++ library computing the real scheme of a T-curve in near-quadratic time. |
| [Orcus.jl](https://github.com/Sequenzer/Orcus.jl) | Quantitative backtesting engine for trading strategies. |
| [Patchworking GUI](https://page.math.tu-berlin.de/~wack/patchworking/patchworking.html) | Browser app for constructing combinatorial patchworks. C++ compiled to WebAssembly. |
| [GroebnerQuantumSym.jl](https://github.com/dmg-lab/GroebnerQuantumSym.jl) | Finite Gröbner bases for quantum symmetric groups. |
| [QuantumAutomorphismGroups.jl](https://github.com/dmg-lab/QuantumAutomorphismGroups.jl) | Computing quantum automorphism groups of matroids. |
| [shannon-contest](https://github.com/Sequenzer/shannon-contest) | Tournament runner for Shannon switching game strategies. |
